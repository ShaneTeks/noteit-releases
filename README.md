# Note'It releases

Public APK releases of **Note'It**, the offline notes app by Shane Technologies CC (Namibia).

The source code is private. This repository holds only signed release APKs, plus a `.sha256` checksum for each APK. The app checks this repository's latest release for updates.

- `app-arm64-v8a-release.apk` is for most modern Android phones.
- `app-release.apk` is a universal APK that runs on all supported devices.

Note'It keeps all notes on the device. Its only network use is checking and downloading updates from this repository.
